# الموقع الشخصي ليوسف

موقع عربي RTL متجاوب، مبني بـ HTML وCSS وJavaScript دون إطار عمل أو خادم خلفي.

## التشغيل محليًا
افتح `index.html` في المتصفح. يمكن استخدام إضافة Live Server في VS Code لتجربة أفضل.

## التعديلات قبل النشر
1. افتح `script.js` وعدّل `email` إلى بريدك الحقيقي.
2. عدّل نبذة التعريف والمهارات داخل `index.html` لتطابق خبرتك الفعلية.
3. أضف روابط مشاريعك وحساباتك الاجتماعية عند توفرها.
4. استبدل اسم العرض «يوسف» إذا أردت اسمًا آخر.

## نشر مجاني عبر GitHub Pages
1. أنشئ حسابًا في https://github.com إذا لم يكن لديك حساب.
2. أنشئ مستودعًا عامًا باسم `USERNAME.github.io` مع استبدال USERNAME باسم حسابك حرفيًا.
3. ارفع جميع ملفات هذا المجلد إلى جذر المستودع: `index.html`, `style.css`, `script.js`, `favicon.svg`.
4. من المستودع افتح Settings ثم Pages، واختر النشر من الفرع `main` والمجلد `/ (root)` إذا لم يكن مفعّلًا تلقائيًا.
5. بعد اكتمال النشر، يكون العنوان عادةً `https://USERNAME.github.io`.

## الدومين والاستضافة
- الاستضافة عبر GitHub Pages مجانية للمستودعات العامة المؤهلة.
- تحصل على عنوان فرعي مجاني من `github.io`، وليس دومينًا مستقلًا مثل `.com`.
- ربط دومين تملكه ممكن من إعدادات Pages، لكن شراء دومين مستقل عادةً مدفوع.
- لا ترفع كلمات مرور أو مفاتيح API أو معلومات خاصة إلى مستودع عام.

## ملاحظات
- الموقع ثابت ولا يجمع بيانات ولا يحتاج قاعدة بيانات.
- خط IBM Plex Sans Arabic يجلب من Google Fonts؛ إذا لم يتوفر الإنترنت سيستخدم المتصفح خطًا بديلًا.
- نموذج التواصل غير موجود عمدًا؛ رابط البريد هو الخيار الآمن والبسيط دون خادم خلفي.
